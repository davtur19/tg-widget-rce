Spray first → free a 64-block hole inside the spray → compile the trigger into
the hole → the far read is pinned to a painted spray block the page owns. This
is immune to region direction, class interleaving, and free-list scatter.

- String drain pad (`"x".repeat(960)`, 1,034 B/block) extends tolerance to
  `N_free ≤ 4,393` blocks under the 8.39 MB cap.
- CPU 21–42 ms host (~120 ms device, ~4× under the slice).
- S2 byte-identical (`2ba2f47f…`, 6,099 chars); probe/final differ in exactly
  one digit (`PRB=0/1`), so bytecode is identical and the calibration
  transfers.
- 6 single-shot probes (coverage ladder 1,500→4,393) + 7 matching finals;
  all 8,477–8,480 raw / zlib9 ≤ 3,607.

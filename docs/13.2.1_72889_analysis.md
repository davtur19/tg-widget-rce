# Android 13.2.1 (72889) — exploit impact analysis

Date: 2026-11-06. APK:
`telegramandroidwidget/apks/Android_Beta_13.2.1_(72889).apk`
(package `org.telegram.messenger.beta`, versionName **13.2.1**, versionCode
**72889**, 79,924,541 B, sha256
`0891db5fb99d08a7cf38393d35f180d7eee66eed872269378ad2deb70c5c99af`).
Reference: 13.2.0 beta **72879** (the build used for the v7 #1827 and #1865
device proofs).

## Verdict

**No exploit-relevant fix.** The quickjs-ng engine code in 72889 is
instruction-identical to 72879 up to `.rodata` address materialization; the
only native changes are a +0x2000 `.rodata` growth/re-layout and the
resulting address relocations. The widget sandbox JS bundles are
**byte-identical** to 72879. The widget TL classes are still present. The
#1827 v7 payload needs **no change**; the #1865 fallback needs only the two
per-build constants updated by +0x2000 (see §4).

Caveat: this is the **beta** 13.2.1. No release 13.2.1 build was available for
comparison; the release branch may differ.

| lib build ID | `3487d62b84b671b180bd20561435ff5b502ae5a3` | `21ec5d5d81f69a9722cf60824e4c296e373bd87b` |

The `.text` size is **exactly equal**; `.rodata` grew by **0x2000**, which
shifted `.text` (and every later section) by +0x2000. `.data.rel.ro`, `.data`,
`.bss`, `.gcc_except_table` and `.eh_frame` keep their sizes. The `.plt`
(6,592 B) is **byte-identical** in both builds.

## 2. Native code diff (72879 → 72889)

Instruction-level comparison of the whole `.text` (AArch64, 4-byte fixed
instructions, Capstone 5.0.7):

- 4,594,699 instructions total.
- **70,656 differing instructions (1.54%)**, 123,307 differing bytes (0.67%).
- **All 70,656 have the same mnemonic**; only address-materialization operands
  differ:
  `add` 39,219, `adrp` 28,597, `ldr` 2,822, `mov` 17, `ldrsb` 1.
- **Zero** differences in branches, compares or logic (`b`, `bl`, `cbz`,
  `tbz`, `cmp`, `ret`, …). The `add`/`adrp`/`ldr` changes are string/data
  references whose targets moved inside the rebuilt `.rodata`.
- The only non-address immediate change is a 17-site `mov w4, #0x7c → #0x8e`
  cluster at `0xEED8DC..0xEEE724` (72879). It is **not quickjs**: the
  surrounding function references libavformat strings
  (`"Failed to read number of events in batch"`, `<HOME>/.../ffmpeg`
  paths). No engine relevance.

Interpretation: the engine was rebuilt with a different `.rodata` layout
(string pooling/link order), not patched. A real fix to #1827/#1865/#1792/
#1835 would have changed the instruction stream (new check, new branch, moved
load) and/or the `.text` size.

## 3. Bug-relevant quickjs functions

Located by unique 48-byte signature match against the annotated 72799 build
(`libmessages_49_arm64_widget_annotated.i64`); every function is at exactly
**+0x2000** in 72889, confirming the uniform shift:

|---|---:|---:|
| `JS_RegExpDelete` (#1827) | `0x17700cc` | **`0x17720cc`** |
| `lre_exec` (#1827) | `0x17b4be4` | **`0x17b6be4`** |
| `js_regexp_Symbol_replace` (#1827) | `0x176d25c` | **`0x176f25c`** |
| `js_array_find` (#1792) | `0x17a04a8` | **`0x17a24a8`** |
| `js_map_finalizer` (#1835) | `0x174389c` | **`0x174589c`** |

The bodies are covered by the global instruction diff above; the #1827 and
#1865 code paths are unchanged relative to 72879, where they were
device-proven:

- #1827 v7 on 72879: proofs 5489/5492/5493, C2 session, app alive.
- #1865 loader on 72879: full C2 session, proof 5504.

## 4. Constants for 13.2.1 (only #1865 needs them)

The v7 #1827 payload resolves `js_def_free → PLT → GOT → libc free → system`
at runtime and uses **no build constants**. The #1865 payload (72879 variant)
needs:

```
JS_DEF_FREE : 0x174b26c     (was 0x174926c)
FREE_GOT    : 0x1971ef0     (was 0x196fef0)
```

Verified end to end on 72889:

```
0x174b26c: e0 03 01 aa   mov x0, x1
0x174b270: 84 cc 05 14   b   0x18be480
0x18be480: adrp x16, #0x1971000
0x18be484: ldr  x17, [x16, #0xef0]     -> 0x1971ef0
```

`readelf -rW` confirms `0x1971ef0 = R_AARCH64_JUMP_SLOT free@LIBC`.
`system` is still resolved from the device libc ELF (`.dynsym`, SysV/GNU
hash), so no libc delta is needed.

## 6. Practical consequence

- **#1827 v7 payload (`minimal_poc/poc.html`)**: expected to work unchanged on
  13.2.1 beta 72889. Same 6 MiB/500 ms sandbox, same engine, same assets.
- **#1865 fallback**: rebuild the 72879 loader with
  `JS_DEF_FREE=0x174b26c`, `FREE_GOT=0x1971ef0` (only these two values change).
- Geometry sensitivity is unchanged; a single device run is not a measurement.
  A controlled run on 72889 is the only remaining validation; no device was
  touched in this analysis.

## 7. Method

- `androguard` for package/version identity.
- `readelf -SW/-rW` for section sizes/addresses and relocations.
- Byte/instruction diff of the full `.text` with Capstone 5.0.7; per-mnemonic
  classification; context check of `add`/`adrp` pairs.
- 48-byte signature matching from the annotated 72799 IDB
  (`libmessages_49_arm64_widget_annotated.i64`) to locate the same functions
  in 72879/72889 (unique matches).
- SHA-256 comparison of the WidgetSandbox assets across 72789/72799/72879/72889.
- DEX string comparison for widget classes/native methods.

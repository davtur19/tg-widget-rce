# iOS 27 17e — stage-A root cause and v13 (2026-11-09)

Status: **host-validated; live matrix running**. No device 90% claim yet.

## Root cause

The parser far read is always `b + 1,311,372` — 1,343.6 class-976 blocks
above `b`. Whether it forges depends on which direction the process
allocator hands `b` its block.

- v0 paints only the **post-`b` spray**. It forges in the favourable
  ("asc") layout and dies in "desc".
- The class-976 free list is shared with Telegram's own allocations, so the
  direction follows the app process state of the day. A byte-identical page
  can hit at one time and die later; this explains the 16:07 success and the
  03:05 failures.
- App version is unchanged: Telegram 13.2 (36535), iOS 27.0 24A437. No app
  patch is involved.

≤7.8 MB. CPU: one 500 ms slice per boot script; v10's 5-round stage A is
329 ms on the host, device factor up to 2.8×; v13 is 29.6 ms.

## cal_heap

`out/cal_heap.html` — 12 boot scripts × 675 KB; the highest rendered `CALk`
bounds the runtime baseline at `8.39 MB − 0.675k MB`. This separates memory
stop from CPU stop from parser fault in one device attempt. K0 gate: k ≥ 8.

## Live K0–K2 (2026-11-09)

- **K0 `cal_heap`: PASS** — highest rendered `CAL11 7425 KB`; runtime baseline
  ≤0.97 MB. CAL12 (8,100 KB) did not render, matching the 8 MiB cap. **Memory
  is not the wall for v13.**
- **K1 v0 control: 2/3 parser deaths + 1 stopped**, 0 markers — the v0
  regression reproduces on the clean chat.
- **K2 v13: 0/2 stage A**, both parser deaths; the matrix stopped on two
  consecutive first-round deaths. No `Render time`, no `RESULT`/`HIT=`, no
  rate.
- The target is outside the painted region in this app state: the
  **non-adjacent geometry wall**, not a v13 page defect and not memory.
- v13 is **not device-proven**; 0/2 is too small for a rate.

Next: 10 fresh v13 launches (the non-adjacent state can re-roll per process),
plus a v14 with the ~3 MB headroom between v13 (4.98 MB) and the 8 MiB stop,
or the exact retry/relaunch probability if the target is a foreign region.

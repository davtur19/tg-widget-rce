# c4096 layout-calibration family (host-only)

## The device fact

On the Sony 72929 (uid 10346, app alive):

| widget | result |
|---|---|
| `c4096_forgeprobe_ladder_72929.html` (B = no-op 7,182) | `S1 ABLEN[599]=327744 VLEN=327744 END=-` |
| `c4096_forgeprobe_legacyB4957_72929.html` (B = no-op 4,957) | `S1 ABLEN[599]=327744 VLEN=327744 END=-` |
| `c4096_forgeprobe_nab900_72929.html` (A nab=900, B no-op) | `S1 ABLEN[599]=327744 VLEN=327744 END=-` |
| `c4096_final_ladder_72929.html` (B = 7,182 endgame) | `S1 NOCORR END=HF ERR NOV` |
| `c3840_forgeprobe_ladder_72929.html` | SIGSEGV `0x1fff9` (unsafe) |

So **class 4096 is correct and the stage A forges**. The final's **B endgame
content changes the pre-stage-A heap** and moves b out of the forge state.
B length (legacyB4957) and nab (nab900) are not the variable; the endgame
**content/allocations** are.

The real bundle harness (`harness/lab_bundle_heap.c`, quickjs-ng + the 72889
`sandbox-bundle.js`) shows the same at boot:

```
forge probe  post-boot(pre-A): malloc_size=3,315,848 used=2,546,226 str=78,933
final         post-boot(pre-A): malloc_size=3,315,848 used=2,549,861 str=82,568
```

The B code string is 7,182 chars in both; the final's pre-A string layout
carries **+3,635 bytes**. Putting the endgame in C/T/eval/comment/encoding
makes the pre-A delta larger (+30 KB for C/T), so the probe-B layout is the
only exact one. The lever must be **runtime heap re-alignment**, not another
carrier.

## The family

All stage A's keep `fsize=3731` (class 4096). The endgame B and stage C are
unchanged. Generated by `gen_c4096_layout.py`; full SHA-256 in `MANIFEST.json`.

**B-length note:** the `fe*` variants keep B exactly 7,182 bytes, so the
existing `SAFE` probe at B=7,182 applies. The `pad*` and `split*` variants
change the B length/structure; the B=7,182 SAFE probe does **not** cover
them — their stage-A mark is the first signal, and a matching B-length probe
would be needed before treating one as a final. They are lower priority.

| priority | file | lever |
|---:|---|---|
| 1 | `c4096_final_fe0_72929.html` | `function f` -> `var f=function` (same fsize); isolates the A form |
| 2-6 | `c4096_final_fe_free{1,2,4,8,16}_72929.html` | K class-4096 chunks allocated and **freed** before b; reorders the b/spray free list, the spray reuses them |
| 7-10 | `c4096_final_fe_8192_free{1,2,4,8}_72929.html` | K class-8192 chunks (the B string class) allocated/freed before b |
| 11 | `c4096_final_fe_8192_keep{1,2,4}_72929.html` | class-8192 live chunks (lower priority) |
| 12-14 | `c4096_final_fe_mix_free{1,2,4}_72929.html` | both classes |
| 15-18 | `c4096_final_fe_keep{1,2,4,8}_...` | K class-4096 live chunks (may occupy the target path; lower priority) |
| 19-23 | `c4096_final_pad{256,512,1024,2048,4096}_...` | endgame B padded with a comment (pre-A length shift) |
| 24-27 | `c4096_final_split{2,3,4,6}_...` | endgame source split into N string scripts, eval in B2 (changes the pre-A string class) |

Host results: all 29 host twins forge (`ABLEN[599]=327744`) and run the
endgame to `HF OK` under `run_sib_plain -l 8`; the Scudo model forges every
preamble A (`stageA` raw, `-m 4k`). Sizes: max **14,317 raw / 4,094 zlib9**
(inside 32,768 / 4,096). The host is **not** device coverage — the c4096
final proves that.

## Next device run (one message per widget)

Run in the table order, stop at the first:

```
S1 ABLEN[599]=327744 VLEN=327744 END=HF OK
```

and check the `n1` proof file. If the mark is `ABLEN` but `END=HF ERR ...
NOANCHOR/NOBASE/NO*`, the stage-A forge is fixed and the remaining blocker is
the endgame anchor; stop and report the exact `END=` string. If the mark is
`NOCORR`, the layout is still wrong; continue. `c3840` must not be run
(SIGSEGV `0x1fff9`).

Minimal first batch (highest information):

```
1 c4096_final_fe0_72929.html
2 c4096_final_fe_free1_72929.html
3 c4096_final_fe_free2_72929.html
4 c4096_final_fe_free4_72929.html
5 c4096_final_fe_8192_free1_72929.html
6 c4096_final_fe_8192_free2_72929.html
7 c4096_final_fe_mix_free1_72929.html
8 c4096_final_pad256_72929.html
```

`fe0` is the cheapest: if the function-expression A form alone re-aligns the
layout, it is the final (no preamble). The free preambles directly change the
class-4096 free list; the 8192/mix ones change the region layout created by
the B string class. `pad256` tests the pure pre-A length shift.

Do not declare the final until a run writes the `n1` proof.
